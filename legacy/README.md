# WolfRogue.dat

Kullanıcının sağladığı Windows istemcisinin ana programı, istenen yeni dosya adıyla bu klasöre kopyalandı. Özgün dosyaya dokunulmadı. Kopyanın SHA-256 değeri `binary-manifest.json` içinde kayıtlıdır.

Bu dosya **32 bit x86 Windows PE programıdır**. Düzenlenebilir oyun kodu, Android çalışma zamanı veya APK değildir. Burada çalıştırılmadı.

Dosya adı `WolfRogue.dat` olarak değiştirildi; dosyanın içeriği, imzaları, gömülü ürün adları ve hizmet başvuruları değiştirilmedi. Tam ürün adı için `branding.json` kullanılır. Derlenmiş programın içindeki adların güvenilir biçimde değiştirilmesi ve Android desteği, kaynak proje üzerinden yeniden derleme gerektirir.

Bu klasör tam bir Windows kurulum paketi değildir. Programın bağımlı olduğu DLL, paket, başlatıcı ve sunucu dosyaları eksik olduğundan bağımsız çalıştığı iddia edilmez.
